# 黄金矿工 Web 版 PRD

2026-10-26

## 概述与目标

用 Web 技术完整复刻经典《黄金矿工》，并加入 RPG 成长和道具商店两个系统，支持单人和本地双人同屏。

- **复刻原版**：摆钩、抓取、按重量回收、限时关卡、目标金额、关间商店。
- **新增系统**：矿工等级与属性、抓钩装备、扩展道具。
- **双人规则**：同一键盘同屏；金币和道具共享，经验和成长各自独立。
- **可扩展**：矿物、小动物、道具、抓钩都是数据配置，新增内容不改系统代码。

首版不做：联网、排行榜、移动端触控。

## 核心玩法

每关 60 秒，玩家放钩抓取地下物体换钱，时间结束时累计金额达到目标即过关，否则游戏结束。

### 钩子状态机

1. **摆动**：钩子在矿工下方左右匀速摆动，等待下钩指令。
2. **伸出**：沿当前角度直线伸出，碰到物体、地图边界或绳长上限即停止。
3. **回收**：带着物体回收，速度 = 基础速度 × 拉力倍率 ÷ 物体重量系数；空钩以最快速度回收。
4. **结算**：物体到达地面时计入金币和经验，钩子回到摆动状态。

### 关卡流程

1. 关卡开始：按关卡配置生成地图，显示目标金额。
2. 挖矿：60 秒倒计时，达到目标后可继续挖到时间结束。
3. 结算：未达标 → 游戏结束；达标 → 各玩家结算经验、升级加点。
4. 商店：购买道具、炸弹、抓钩。
5. 整备：调整快捷栏、分配抓钩，进入下一关。

## 游戏模式与操控

单人模式一个矿工居中；双人模式两个矿工分站地面左右，各有独立钩子，同屏共用一个键盘。

| 操作 | P1 | P2 |
| --- | --- | --- |
| 下钩 | S | ↓ |
| 炸弹 | W | ↑ |
| 道具 1–9 | 数字键 1–9（两人共用） | 小键盘 1–9（与数字键等效，方便右手） |
| 暂停 | Esc | Esc |

- 按键用 `KeyboardEvent.code` 绑定，不受输入法和键盘布局影响；按键表做成配置，可在设置中改键。
- **炸弹**只作用于按键者自己的钩子；钩子未带物体时按炸弹无效，也不消耗。
- **普通道具**由任意一人按数字键使用，效果作用于全体玩家。
- **双钩争抢**：物体被一个钩子抓住后，另一个钩子会穿过它；两钩之间不发生碰撞。

## 经济系统

金币全队共享，第 1 关目标 650，之后按二次曲线增长，第 10 关达到 15275；双人目标为单人的 1.6 倍。

- 收益 = 物体基础价值经修饰器管线计算后的结果（石头书、抛光剂、暴击等都在这里生效）。
- 金币用途：购买炸弹、普通道具、被动 buff、抓钩。
- 第 n 关单人目标金额：

```latex
T(n) = 650 + 545(n-1) + 135(n-1)(n-2)
```

## 道具系统

道具分三类：炸弹（独立槽位、共享池、各自触发）、主动道具（共享背包、数字键使用、全体生效）、被动 buff（购买后下一关自动生效）。

### 炸弹

- 全队共用一个炸弹池，HUD 单独显示数量，不占快捷栏。
- P1 按 W、P2 按 ↑，炸掉自己钩上正在回收的物体，钩子立即空钩收回；被炸物体无收益、无经验。
- 商店每关固定上架，基础价 150。

### 主动道具

| 道具 | 效果 | 持续 | 基础价 |
| --- | --- | --- | --- |
| 冰冻炸弹 | 冻住所有小动物，冻住期间不移动 | 3 秒 | 200 |
| 沙漏 | 本关剩余时间 +10 秒 | 即时 | 250 |
| 磁石 | 每位玩家的下一钩吸附落点周围的小金块，一并带回 | 每人下一钩 | 300 |
| 透视镜 | 显示所有神秘袋的内容 | 本关 | 150 |
| 猪饲料 | 小动物向地图中央聚集 | 5 秒 | 120 |
| 防爆盔 | TNT 爆炸不会炸毁钩上的物体 | 本关 | 180 |

- 快捷栏 9 格，对应数字键 1–9；每种道具占一格并显示数量，整备界面可调顺序。
- 道具种类超过 9 种时，只有放入快捷栏的才能在局内使用。

### 被动 buff

| 道具 | 效果 | 基础价 |
| --- | --- | --- |
| 大力水 | 全体回收速度提升 | 250 |
| 四叶草 | 神秘袋开出好东西的概率提升 | 150 |
| 石头收藏书 | 石头价值 ×3 | 100 |
| 钻石抛光剂 | 钻石价值 +50% | 300 |

### 商店规则

- 每关结算后进入商店，炸弹固定上架，另随机上架 `shopSlots` 件主动道具或被动 buff，按各道具的 `appearRate` 加权抽取。
- 价格 = 基础价 × (1 + 0.1 × (关卡 − 1))，再随机浮动 ±20%。
- 双人模式下任意一人可发起购买，另一人按键确认后成交，避免一人花光共享金币。

已删除：双爪、速收卷轴、点金石（单钩效果与全体生效规则冲突，或数值过强）。

## 抓钩装备

装备只有抓钩一种。抓钩用金币购买后进入共享背包，每把是一件独立实例，同一时间只能被一名玩家装备。

| id | 名称 | 价格 | 伸出速度 | 回收倍率 | 判定半径 | 特性 |
| --- | --- | --- | --- | --- | --- | --- |
| basic | 铁钩 | 初始 | ×1.0 | ×1.0 | ×1.0 | — |
| scope | 瞄准钩 | 600 | ×1.0 | ×1.0 | ×1.0 | 摆动时显示虚线引导线 |
| swift | 疾风钩 | 800 | ×1.5 | ×1.3 | ×1.0 | — |
| claw | 巨爪 | 1000 | ×0.9 | ×1.0 | ×1.6 | — |
| saw | 锯齿钩 | 1500 | ×1.0 | ×1.0 | ×1.0 | 伸出时杀死路径上的小动物 |

### 规则

- 每位玩家开局自带一把铁钩，铁钩不可出售。
- 两人都想用同款，需要购买两把；也可在整备界面互换。
- **锯齿钩**：伸出途中碰到小动物即杀死，钩子不停、继续向下；被杀的小动物无金币、无经验；钻石猪携带的钻石留在原地，可被正常抓取。
- 抓钩数值作用于装备者的玩家层修饰器，不影响另一名玩家。

### 特性组合

抓钩 = 数值 + 特性列表。特性是注册表中的独立模块，挂在钩子系统事件上：

- `aimLine`：在 `onSwing` 时绘制引导线。
- `killPath`：在 `onExtendTick` 时检测路径上的小动物并杀死。

新抓钩只需一行配置，也可以组合多个特性，例如 "疾风 + 瞄准"。

## RPG 成长系统

经验只属于把物体拉回地面的那名玩家，用于提升矿工等级；双人模式下两人的等级、属性点和天赋完全独立。

### 经验获取

- 经验 = 物体最终价值 × 0.2 + 类型奖励（钻石 30、猪 15、神秘袋 10）。
- 被炸毁的物体、被锯齿钩杀死的小动物不产生经验。
- 升到下一级所需经验 = round(100 × 当前等级^1.5)，Lv1→2 需 100，Lv5→6 需 1118，Lv10→11 需 3162。

### 属性

每升一级获得 3 点属性点，在关卡结算界面自由分配，双人各自加点。

| 属性 | 每点效果 |
| --- | --- |
| 力量 | 回收速度 +3% |
| 敏捷 | 伸出速度 +3%，摆动速度 +1% |
| 精准 | 抓取判定半径 +2% |
| 幸运 | 神秘袋品质提升；暴击率 +0.5%（暴击 = 该物体价值 ×2） |

### 天赋

Lv5、10、15、20 时各获得一次天赋选择，从随机 3 个中选 1 个。示例：

- 钻石猎人：抓到钻石时本关时间 +2 秒。
- 碎石专家：石头价值 ×2。
- 爆破手：使用炸弹后返还 50% 被炸物体价值。
- 老练：空钩回收速度 +50%。

## 技术架构与扩展性

技术栈为 Vite + React + TypeScript + TanStack Router / Store / Query，游戏画面用 Canvas 2D；引擎与内容分离，所有内容通过注册表接入。

| 技术 | 职责 |
| --- | --- |
| TanStack Router | 页面流转：菜单 → 游戏 → 结算 → 商店 → 整备 |
| TanStack Store | 钱包、炸弹池、背包、快捷栏、玩家等级与装备；HUD 和商店订阅 |
| TanStack Query | 存档读写，先用 localStorage，后续可换后端 |
| Canvas 2D | 游戏循环独立于 React，用固定步长；只有金币、经验等变化才写入 Store |

### 数据模型

```ts
type RunState = {
  mode: 'solo' | 'duo';
  level: number;
  wallet: number;                          // 共享金币
  bombs: number;                           // 共享炸弹池
  items: Record<ItemId, number>;           // 共享主动道具
  buffs: BuffId[];                         // 下一关生效的被动 buff
  hotbar: (ItemId | null)[];               // 9 格
  hooks: { uid: string; defId: HookId }[]; // 共享背包里的抓钩实例
  players: PlayerState[];

  id: 'p1' | 'p2';

  stats: { str: number; agi: number; acc: number; luk: number };
  talents: TalentId[];

```

### 修饰器管线

所有数值（价值、速度、半径、时间）都经过两层修饰器计算，新增内容只需挂函数，不改系统。

- **玩家层** `player.mods`：抓钩、属性、天赋。
- **全局层** `run.mods`：主动道具、被动 buff。
- 计算顺序：基础值 → 玩家层 → 全局层。

```ts
// 石头收藏书
apply: run => run.mods.add('value', (v, m) => m.tags.includes('rock') ? v * 3 : v)
```

### 可扩展点

矿物、小动物、小动物行为、主动道具、被动 buff、抓钩、抓钩特性、天赋各有一个注册表，新增内容 = 在 `content/` 加一个定义文件并在 `index.ts` 注册。
